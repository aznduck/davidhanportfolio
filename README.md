# davidhanportfolio

v2 of my personal site. v1 lives on, frozen, at [aznduck.github.io](https://aznduck.github.io).

- Stack: Vite + React + TypeScript + Tailwind v4, deployed on Vercel.

```sh
npm install
npm run dev
```
